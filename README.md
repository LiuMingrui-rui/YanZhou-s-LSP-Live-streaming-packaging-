# 🎭 晚会综合管理系统

一个功能完善的学校晚会综合管理控制系统，支持节目单展示、主持人字幕、Logo 挂角显示和实时比分计分板等功能。

## ✨ 主要功能

### 📋 节目单管理
- 支持添加、编辑、删除节目信息
- 包含节目编号、类型、标题、表演者和描述等详细信息
- 实时切换显示当前节目
- 自动显示下一个节目预告

### 🎤 主持人字幕条
- 支持多主持人信息管理
- 可配置左右两侧主持人显示
- 多种颜色主题可选（玫瑰红、紫色、蓝色、绿色等）
- 支持主持人位置调整
- 预设快速切换功能

### 🏆 实时计分板
- 双队比分实时显示（红队/蓝队）
- 支持自定义队伍名称和班级
- 犯规次数统计
- 比赛时钟和进攻计时器
- 一键隐藏/显示比分

### 🎨 Logo 挂角显示
- 支持台标/校徽悬浮显示
- 可调节位置和透明度
- 交替显示模式
- 支持自定义图片

### 🎛️ 集中控制面板
- 统一控制所有显示端
- 深色/浅色主题切换
- 实时状态同步
- 响应式设计，支持移动端操作

## 🛠️ 技术栈

- **后端**: Python 3 + HTTP Server
- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **通信**: SSE (Server-Sent Events) 实时推送
- **数据格式**: JSON
- **优化**: Gzip 压缩、ETag 缓存、状态缓存

## 🚀 快速开始

### 环境要求
- Python 3.6 或更高版本
- 现代浏览器（Chrome、Edge、Firefox、Safari）

### 启动步骤

1. **启动服务器**
   ```bash
   # 方式一：使用批处理文件（Windows）
   启动服务器.bat
   
   # 方式二：命令行启动
   python server.py
   ```

2. **访问各功能页面**
   
   服务器启动后，在浏览器中访问以下地址：
   
   - **控制面板**: `http://localhost:8000/public/controller.html`
   - **计分板**: `http://localhost:8000/public/scoreboard.html`
   - **节目单**: `http://localhost:8000/public/program.html`
   - **主持人字幕**: `http://localhost:8000/public/host.html`
   - **Logo 挂角**: `http://localhost:8000/public/logo.html`

3. **使用说明**
   - 在控制面板进行所有操作
   - 其他页面会自动同步显示
   - 建议使用多个显示器分别显示不同内容
   - 通过 OBS 等软件捕获浏览器窗口进行直播推流

## 📖 配置说明

### 节目单配置 (`programs.json`)

```json
{
  "number": "01",           // 节目编号
  "type": "舞蹈",           // 节目类型
  "title": "双生",          // 节目标题
  "performer": "高二2班...", // 表演者
  "desc": "节目描述..."      // 节目简介
}
```

### 主持人配置 (`hosts.json`)

```json
{
  "name": "周子谈",         // 主持人姓名
  "title": "高一（30）班",  // 班级/头衔
  "bio": "",               // 个人介绍（可选）
  "photo": ""              // 照片路径（可选）
}
```

### 系统设置 (`settings.json`)

```json
{
  "theme": "dark"          // 主题：dark（深色）或 light（浅色）
}
```

## 🔧 API 接口

### 状态获取
- `GET /api/state` - 获取完整状态
- `GET /api/lite-state` - 获取精简状态
- `GET /api/events` - SSE 实时事件流
- `GET /api/hosts` - 获取主持人列表
- `GET /api/settings` - 获取系统设置

### 状态更新
- `POST /api/state` - 更新状态

### 数据管理
- `PUT /programs.json` - 更新节目单
- `PUT /hosts.json` - 更新主持人信息
- `PUT /presets.json` - 更新预设配置
- `PUT /settings.json` - 更新系统设置

## 💡 使用技巧

1. **多屏布局建议**
   - 主屏幕：控制面板（操作员使用）
   - 副屏幕1：计分板（观众可见）
   - 副屏幕2：节目单（后台监控）
   - OBS 捕获：主持人字幕 + Logo（直播叠加）

2. **OBS 直播设置**
   - 添加"浏览器源"
   - 设置透明背景
   - 调整尺寸和位置
   - 启用"刷新浏览器时关闭硬件加速"

3. **快捷键操作**
   - 控制面板支持快速切换节目
   - 预设按钮一键切换常用布局
   - 比分快捷加减操作

4. **性能优化**
   - 系统自动启用 Gzip 压缩
   - 静态资源缓存优化
   - SSE 心跳保持连接
   - 状态变更增量推送

## 📝 注意事项

1. 确保防火墙允许 8000 端口访问
2. 建议使用 Chrome 或 Edge 浏览器以获得最佳体验
3. 局域网使用时，将 `localhost` 替换为服务器 IP 地址
4. 定期备份 `programs.json` 和 `hosts.json` 数据
5. 修改 JSON 文件后无需重启服务器，自动生效

## 🐛 故障排除

**问题：页面无法访问**
- 检查 Python 是否正常安装
- 确认 8000 端口未被占用
- 检查防火墙设置

**问题：状态不同步**
- 刷新浏览器页面
- 检查网络连接
- 查看浏览器控制台错误信息

**问题：中文显示乱码**
- 确保文件编码为 UTF-8
- 检查浏览器字符集设置
